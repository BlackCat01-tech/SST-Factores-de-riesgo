# SENA POMAR: GIMNASIO — Factores de riesgo e impacto ambiental

Página web educativa sobre Seguridad y Salud en el Trabajo (SST) en un gimnasio.

- Factores de riesgo: físico, químico, de seguridad, biológico, psicosocial, biomecánico y fenómenos naturales.
- Módulo "Impacto ambiental": 3 impactos negativos y 3 positivos.

## Estructura
```
index.html
assets/   (logo y fotos)
```

## Cómo publicarla en GitHub Pages
1. Crea un repositorio nuevo en GitHub y sube `index.html` y la carpeta `assets/`.
2. Ve a **Settings → Pages**.
3. En *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarda.
4. En 1 o 2 minutos la página estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
